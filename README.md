# トークテーマダイス

ブラウザ上で動作する、3D物理演算を用いたトークテーマ決定ツールです。
配信、イベント、飲み会などでの話題決めに活用できます。

## 特徴

* **リアルな物理演算**: 実際にダイスを転がしているようなリアルな挙動が楽しめます。

* **オフライン動作対応**: ブラウザ上で完結するため、一度読み込めばオフライン環境でも動作します。

* **進行管理の自動化**: 一度出たテーマの記録や、被った際の自動振り直し機能を搭載しています。

## 使い方

### 1. 起動方法

本ファイル群に含まれるHTMLファイルを、お使いのWebブラウザ（Google Chrome, Apple Safari, Microsoft Edge など）にドラッグ＆ドロップするか、ダブルクリックして開いてください。

### 2. トークテーマの設定

画面左上にある「トークテーマ一覧」のパネルに、ダイスの6つの面に設定したいトークテーマを入力してください。
入力した内容は、リアルタイムで画面上の3Dダイスに反映されます。

### 3. ダイスを振る

画面下部の「**ダイスを振る**」ボタンをクリック（またはタップ）すると、ダイスが転がります。
ダイスが静止すると、出た目のテーマが画面中央にポップアップ表示されます。
（※ポップアップは右上の「×」ボタンで閉じることができます）

### 4. アプリの仕様と便利機能

* **編集ロック**: 一度でもダイスを振ってトークが進行中になると、途中でテーマが変更されないよう入力欄がロックされます。

* **出た目の記録**: 一度出たテーマには自動的に「✅」マークが付き、一覧でグレーアウトされます。

* **自動振り直し**: 既に「✅」が付いている（過去に出た）目が再び出た場合、アプリが自動的にもう一度ダイスを振り直します。

* **最後の1つ**: 5つのテーマが出揃うと、ボタンが「**最後のテーマを見る**」に変化します。このボタンを押すと、残った最後のテーマが自動的に確定し、専用の演出で表示されます。

### 5. リセット方法

画面下部の「**トークをやめる**」ボタンを押すと、進行状況（✅の状態やロック状態）がリセットされ、最初の状態に戻ります。

* ※この際、入力したトークテーマのテキスト内容は保持されるため、同じテーマで再度遊びたい場合に再入力する手間はかかりません。

## 動作環境

* HTML5 / WebGL に対応した最新のPC・スマートフォン用ブラウザ推奨。

* ※注意: 初回起動時のみ、物理演算などの描画エンジン（Three.js / Cannon.js）をインターネット経由で読み込みます。完全にネットから遮断された環境で起動したい場合は、ソースコード内のCDN URLからライブラリをダウンロードし、ローカルに配置してください。
